SSTI Playground

Server-Side Template Injection (FastAPI & Jinja2 Lab)

Status: Vulnerable

Apa itu SSTI?

Server-Side Template Injection (SSTI) terjadi ketika input dari pengguna dimasukkan langsung ke dalam string template tanpa dibersihkan (sanitized). Hal ini memungkinkan penyerang menyuntikkan arahan sintaks template engine untuk dieksekusi di sisi server.

Goal CTF: Coba dapatkan RCE (Remote Code Execution) untuk membaca file sistem!

Payload Test: ?name={{7*7}} atau ?name={{''.__class__.__mro__}}

Uji Input Kamu

Hasil Render Template (Server Output):

{name}
